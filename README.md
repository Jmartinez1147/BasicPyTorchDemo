# Basic PyTorch Demo

## Dataset

Iris Dataset

150 flower samples with four measurements:

- sepal_length_cm
- sepal_width_cm
- petal_length_cm
- petal_width_cm

Target:

- species

## PyTorch Concepts

- Tensors
- Gradients
- Linear Layers
- Activation Functions
- CrossEntropyLoss
- Adam Optimizer
- Neural Networks

## Results

Final Test Accuracy: 1.0

New Flower Prediction: setosa

Reloaded Prediction: setosa

## Summary

A PyTorch neural network was trained to classify iris flowers.

The network used one hidden layer and ReLU activation.

Weights were saved and successfully reloaded.
